# Luneli — Site Oficial (luneli.com.br)

Site institucional e comercial da **Luneli** — Sistema de gestão e PDV para restaurantes, pizzarias e delivery.

## Tecnologias
- [Astro](https://astro.build) (Static Site Generation)
- CSS com variáveis tipográficas e tipografia customizada
- Cloudflare Pages + Cloudflare DNS

## Desenvolvimento Local
```bash
npm install
npm run dev
```

## Build de Produção
```bash
npm run build
```
O build estático é gerado na pasta `dist/`.
